# ЛР5. Вариант 25
### Bash-скрипт: удаление файлов по суммарному размеру в блоках

В проекте реализован bash-скрипт [`lab_bash.sh`](./lab_bash.sh), который удаляет файлы из одного или нескольких каталогов до тех пор, пока суммарный размер удаленных файлов не станет больше или равен заданному числу блоков.

Скрипт поддерживает справку, интерактивный ввод числа блоков, добавление текущей директории в список обработки и тихий режим вывода.

## Идея и метод решения

Скрипт получает список директорий и число блоков, которое нужно набрать удалением файлов. Число блоков передается через параметр `-b` или `--blocks`.

Файлы удаляются сразу во время обхода каталогов. После каждого удаления размер файла в блоках прибавляется к общей сумме. Как только сумма становится больше или равна заданному числу блоков, скрипт выводит итоговую статистику и завершает работу.

В этой версии скрипт не собирает список файлов заранее. Он идет по каталогам последовательно и удаляет подходящие обычные файлы до достижения нужной суммы.

> [!IMPORTANT]
> Скрипт считает именно сумму уже удаленных файлов. Если нужное число блоков набрано раньше, дальнейший обход каталогов прекращается.

## Параметры запуска

Скрипт поддерживает следующие параметры:

| **Параметр** | **Назначение** |
|:------------|:---------------|
| `?`, `-h`, `--help` | вывести справку |
| `-b`, `--blocks` | указать нужное число блоков |
| `-i`, `--interactive` | запросить число блоков интерактивно, если оно не передано |
| `-c`, `--current` | добавить текущую директорию в список обработки |
| `-q`, `--quiet` | скрыть подробный вывод об удаляемых файлах |

Пример запуска:

```bash
./lab_bash.sh ./test -b 20
```

Пример с несколькими директориями:

```bash
./lab_bash.sh ./dir1 ./dir2 -b 50
```

Пример с текущей директорией:

```bash
./lab_bash.sh -c -b 10
```

## Алгоритм

1. Проверить, не запрошена ли справка
2. Разобрать параметры командной строки
3. Сохранить число блоков из `-b` или `--blocks`
4. Сохранить все переданные директории в массив `DIRS`
5. Если включен интерактивный режим и число блоков не задано, запросить его у пользователя
6. Если указан `-c` или `--current`, добавить текущий каталог в список директорий
7. Проверить, что список директорий не пустой
8. Проверить, что число блоков задано и является целым неотрицательным числом
9. Последовательно пройти по файлам в указанных директориях
10. Для каждого обычного файла получить размер в блоках через `stat -c %b`
11. Удалить файл командой `rm`
12. Прибавить размер файла к общей сумме удаленных блоков
13. Увеличить счетчик удаленных файлов
14. Если сумма достигла нужного значения, вывести статистику и завершиться
15. Если файлы закончились раньше, вывести, сколько удалось удалить

## Тонкости реализации

В этой лабораторной важно было аккуратно связать обход каталогов, подсчет блоков и удаление файлов. Скрипт работает не с абстрактным списком, а с реальными файлами, поэтому порядок проверок здесь имеет значение.

При реализации нужно учитывать:

- директории передаются как позиционные аргументы
- число блоков передается через `-b` или `--blocks`
- при `-i` число блоков можно запросить через `read`
- при `-c` в обработку добавляется текущий каталог `$PWD`
- подробный вывод можно выключить через `-q`
- обрабатываются только обычные файлы, для этого используется проверка `-f`
- размер файла берется в блоках через `stat -c %b`
- файл удаляется до прибавления его размера к общей статистике
- как только нужная сумма набрана, скрипт завершает работу через `exit 0`
- если файлов не хватило, выводится итоговая информация о фактически удаленных файлах и блоках

> [!NOTE]
> В shell особенно важно оборачивать пути в кавычки. В скрипте это используется при обходе директорий и удалении файлов, чтобы имена с пробелами не ломали команды.

Кратко про обработку ошибок: скрипт сообщает, если не передано ни одной директории, если после `-b` не указано число блоков, если число блоков не является целым числом или если оно вообще не задано.

## Сложность

Скрипт проходит по файлам в переданных директориях до тех пор, пока не наберет нужную сумму блоков или пока файлы не закончатся.

| **Операция** | **Сложность** |
|:------------|:--------------|
| разбор параметров | `O(m)`, где `m` - количество аргументов |
| обход файлов | `O(n)`, где `n` - количество найденных файлов |
| подсчет суммарного размера | `O(n)` |
| удаление файлов | `O(k)`, где `k` - количество удаленных файлов |
