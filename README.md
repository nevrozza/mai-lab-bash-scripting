# ЛР21. Вариант 25
### Bash-скрипт: удаление файлов по суммарному размеру в блоках

В проекте реализован bash-скрипт для обработки файлов в каталоге и удаления такого набора файлов, суммарная длина которого не меньше заданного числа блоков.

По условию лабораторной работы сценарий обрабатывает параметры командной строки, поддерживает справку, трассировку и корректно реагирует на ошибочные ситуации.

> [!NOTE]
> Здесь важно было не просто вызвать команду удаления, а сначала аккуратно собрать список файлов. Скрипт считает размер каждого файла в блоках, накапливает сумму и останавливает выбор, когда нужный порог уже достигнут.

## Идея и метод решения

Скрипт получает входные параметры, проверяет их корректность, затем просматривает файлы в указанном каталоге и определяет их размер в блоках.

После этого файлы последовательно добавляются в список на удаление. Для каждого выбранного файла его размер прибавляется к общей сумме. Как только сумма становится не меньше заданного числа блоков, выбранные файлы удаляются.

Файлы не удаляются сразу в момент первого обхода. Сначала формируется набор, который подходит под условие, и только потом выполняется удаление. Так проще контролировать, что именно будет удалено.

> [!IMPORTANT]
> В этой задаче важно не перепутать условие: нужно удалить не один файл нужного размера, а набор файлов, суммарная длина которых не меньше заданного числа блоков.

## Структура программы

Логически сценарий можно разделить на несколько частей:

- разбор параметров командной строки
- вывод справки при запросе пользователя
- включение трассировки для отладки
- проверка существования каталога
- проверка заданного числа блоков
- поиск файлов в каталоге
- вычисление размера каждого файла в блоках
- накопление общей суммы
- удаление выбранных файлов
- обработка ошибочных ситуаций

Удаление файлов является необратимой операцией, поэтому перед ним нужно отдельно проверить параметры, каталог и сам список выбранных файлов.

## Алгоритм

1. Считать параметры командной строки
2. Если запрошена справка, вывести описание использования скрипта
3. Если включена трассировка, активировать вывод выполняемых команд
4. Проверить, что заданный путь существует и является каталогом
5. Проверить, что число блоков является корректным положительным числом
6. Найти файлы, подходящие для обработки
7. Для каждого файла определить размер в блоках
8. Добавить файл в список на удаление и увеличить накопленную сумму
9. Остановить выбор файлов, когда сумма стала не меньше заданного числа блоков
10. Если нужная сумма набрана, удалить выбранные файлы
11. Если нужная сумма не набрана, вывести сообщение и не выполнять удаление

## Тонкости реализации

В этой лабораторной много внимания ушло на безопасное поведение сценария. Команда удаления сама по себе простая, но ошибка в выборе файлов может привести к удалению не того набора.

При реализации нужно учитывать:

- считается именно суммарный размер выбранных файлов
- размер сравнивается с заданным числом блоков
- после достижения нужной суммы выбор файлов останавливается
- перед удалением проверяется, что список файлов не пустой
- каталоги не должны обрабатываться как обычные файлы
- пустой каталог должен обрабатываться спокойно
- файлы без прав доступа не должны ломать весь сценарий без понятного сообщения
- некорректные параметры не должны приводить к удалению

> [!IMPORTANT]
> Имена файлов лучше обрабатывать через кавычки и безопасный обход. Иначе файл с пробелом в имени может неожиданно превратиться для shell в несколько разных аргументов.

Кратко про обработку ошибок: сценарий учитывает несуществующий каталог, неправильное число параметров, некорректное значение числа блоков, пустой каталог, отсутствие подходящих файлов и ошибки доступа. В таких случаях скрипт выводит понятное сообщение и не выполняет опасные действия.

> [!NOTE]
> При отладке удобно использовать трассировку: она показывает, какие команды выполняются и какие значения получают переменные во время работы скрипта.

## Сложность

Сценарий просматривает файлы в каталоге. Если в каталоге находится `n` файлов, то в худшем случае нужно проверить каждый из них.

| **Операция** | **Сложность** |
|:------------|:--------------|
| обход файлов | `O(n)` |
| подсчет суммарного размера | `O(n)` |
| удаление выбранных файлов | `O(k)`, где `k` - количество удаляемых файлов |
